# تثبيت واختبار تطبيق الذاكرة على الجوال — MusabAI Memory

دليل موجز لتنفيذ: **«نزّله ونصّبه على الجوال واختبره»**.

## رابط التنزيل المباشر
https://github.com/Musabgpt/C66/releases/download/task-memory-latest/MusabAI-TaskMemory.apk

افتحه من **Chrome** على الجوال. الرابط ثابت ويقدّم دائماً أحدث بناء ناجح من هذا الفرع
(تنشره مهمة `publish-memory-apk` في CI). صفحة الإصدار مع ملاحظاته:
https://github.com/Musabgpt/C66/releases/tag/task-memory-latest

## الحزمة
- اسم الحزمة: `dev.newal.code.lite.connectors`. بصمة SHA‑256 لكل بناء في ملف
  `MusabAI-TaskMemory.apk.sha256` المنشور بجانبه.
- التوافق: `minSdk 26` (أندرويد 8.0) حتى `targetSdk 35` (أندرويد 15).
- موقّع بمفتاح التطوير الثابت من CI، فكل بناء جديد يُثبَّت فوق السابق. بصمة التوقيع:
  `ecced2e9c9df7d31e43f1aaeaabef6c3fa03387017915112193488286bd2a7fb`

## التثبيت
1. افتح الرابط من Chrome، فيبدأ التنزيل.
2. اضغط على الملف بعد انتهاء التنزيل. إن طُلب منك، اسمح لـ Chrome بـ «تثبيت تطبيقات غير معروفة»
   (`الإعدادات ← التطبيقات ← وصول خاص ← تثبيت تطبيقات غير معروفة`) ثم اضغط **تثبيت**.
3. إن ظهرت «لم يتم تثبيت التطبيق»: احذف نسخة MusabAI القديمة أولاً (تكون موقّعة بمفتاح آخر) ثم ثبّت من جديد.

بعد التثبيت تظهر أيقونتان: **MusabAI Preview** (التطبيق والنموذج) و**ذاكرة المهام** (تطبيق الذاكرة).

## الاختبار على الجهاز
1. افتح **ذاكرة المهام** واكتب في «جرّب طلباً»: **افتح الفيس بوك انشر منشور**.
   يظهر الإجراء المطابَق من القاعدة المصنّفة مع خطواته بالترتيب.
2. اضغط **تشغيل** لتنفيذ الخطوات على الجهاز (يتطلّب تفعيل خدمة إمكانية الوصول عند الطلب).
3. للتجربة عبر النموذج: افتح **MusabAI Preview** واطلب «افتح الفيس بوك انشر منشور» — يقرأ النموذج
   الخطوات من الذاكرة عبر `phone_routine tm:cur.facebook.post` وينفّذها ثم يردّ بالعربية بأن المهمة تمّت.

## بديل: التثبيت عبر الحاسوب (adb)
```
adb install -r MusabAI-TaskMemory.apk
adb shell am start -n dev.newal.code.lite.connectors/dev.newal.code.lite.TaskMemoryActivity
```
يتطلّب تفعيل **USB debugging** على الجوال ووصله بحاسوب موثوق.
