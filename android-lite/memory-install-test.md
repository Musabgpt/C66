# تثبيت واختبار تطبيق الذاكرة على الجوال — MusabAI Memory

دليل موجز لتنفيذ: **«نزّله ونصّبه على الجوال واختبره»**.

## الحزمة
- الملف: `MusabAI-0.1.98-TaskMemory.apk` (مُرسَل في المحادثة).
- SHA‑256: `378bc20192b543a222532e7ecc07127b5b66ee1724c16982a8bc875248236745`
- التوافق: `minSdk 26` (أندرويد 8.0) حتى `targetSdk 35` (أندرويد 15) — يعمل على أي هاتف حديث.
- موقّع بمفتاح التطوير من CI (run 98). بصمة التوقيع:
  `ecced2e9c9df7d31e43f1aaeaabef6c3fa03387017915112193488286bd2a7fb`

## التثبيت (نقرة منك — لا يمكن لطرف بعيد تجاوز حاجز أمان أندرويد)
1. فعّل تثبيت المصادر غير المعروفة لمصدر الملف:
   `الإعدادات ← التطبيقات ← وصول خاص ← تثبيت تطبيقات غير معروفة` ثم فعّلها لتطبيق «الملفات» أو المتصفح.
2. اضغط على ملف الـ APK ← **تثبيت** ← **فتح**.

## الاختبار على الجهاز
1. من الشاشة الرئيسية للتطبيق اكتب في «جرّب طلباً»: **افتح الفيس بوك انشر منشور**.
   يظهر الإجراء المطابَق من القاعدة المصنّفة مع خطواته بالترتيب.
2. اضغط **تشغيل** لتنفيذ الخطوات على الجهاز (يتطلّب تفعيل خدمة إمكانية الوصول عند الطلب).
3. للتجربة عبر النموذج: اطلب «افتح الفيس بوك انشر منشور» في المحادثة — يقرأ النموذج الخطوات من
   الذاكرة عبر `phone_routine tm:cur.facebook.post` وينفّذها ثم يردّ بالعربية بأن المهمة تمّت.

## بديل: التثبيت عبر الحاسوب (adb)
```
adb install -r MusabAI-0.1.98-TaskMemory.apk
adb shell monkey -p dev.newal.code.lite -c android.intent.category.LAUNCHER 1
```
يتطلّب تفعيل **USB debugging** على الجوال ووصله بحاسوب موثوق.

> ما تمّ من الطرف البرمجي: البناء، والاختبار على نظام أندرويد (Android‑x86 9)، والتوقيع، والتسليم.
> الخطوة الأخيرة (نقرة التثبيت على جهازك الفعلي) هي وحدها ما يتطلّب تدخّلك.
