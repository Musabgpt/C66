# 🤖 Mobile AI Agent — مساعد ذكاء اصطناعي متكامل للجوال

مساعد يعمل **محلياً على جهازك** داخل Termux: يتحدث معك، يتصفّح الويب أمام عينيك،
يتحكم بالهاتف، يدير مستودعات GitHub، ويجدول مهامّ تعمل في الخلفية وتُرسل لك إشعارات.

لا سحابة ولا اشتراك — واجهة ويب واحدة (PWA) + خادم FastAPI محلي + موجّه نماذج مجانية.

## الملفات
| الملف | الوصف |
|------|-------|
| `setup.sh` | يثبّت كل شيء في Termux، وينشئ اختصار Termux:Widget على الشاشة الرئيسية وملف PWA. |
| `backend.py` | خادم FastAPI: حلقة الوكيل (ReAct)، أدوات المتصفح/GitHub/Termux، المجدول. |
| `index.html` | الواجهة كاملةً (HTML + Tailwind + JS) في ملف واحد، وضع داكن، 4 تبويبات. |

## التثبيت (داخل Termux)
```bash
bash setup.sh
# ضع مفتاحاً مجانياً واحداً على الأقل في ~/.mobile-agent.env ثم:
./run.sh
```
يفتح المتصفح على `http://127.0.0.1:8900`. اختر **"إضافة إلى الشاشة الرئيسية"** لأيقونة التطبيق،
أو استخدم ودجت **Termux:Widget → AI-Agent** لتشغيله بلمسة.

## المفاتيح المجانية (يكفي واحد)
- **Gemini** (الأساسي): https://aistudio.google.com/apikey
- **OpenRouter** (نماذج مجانية): https://openrouter.ai/keys
- **Groq**: https://console.groq.com/keys

الموجّه يجرّب Gemini أولاً، ثم يتحوّل تلقائياً إلى OpenRouter أو Groq عند نفاد الحصّة.

## التبويبات الأربعة
1. **محادثة** — أوامر نصيّة وصوتية، مع عرض حيّ لكل إجراء يقوم به الوكيل ونطق الردود.
2. **المتصفح الحيّ** — بثّ لقطات الشاشة، شريط عنوان، والمس الصورة للنقر والتدخّل يدوياً.
3. **الجدولة** — أضِف مهامّ (cron أو كل N دقيقة)، فعّل/عطّل، شغّل الآن، وسجلّ النتائج.
4. **اللوحة** — حالة الاتصال، أزرار Push/Pull لـ GitHub، واختبار إشعارات الهاتف.

## الأدوات المتاحة للوكيل
- `browser_open / click / type / press / extract_text / screenshot` — متصفّح حقيقي (Playwright).
- `github_tool` — status / create_repo / clone / pull / read_file / write_file / commit_push.
- `termux_tool` — shell / notify / clipboard / open_app / volume.
- `schedule_task` — يجدول مهمة خلفية من داخل المحادثة.

> مثال: «كل يوم الساعة 9 صباحاً افتح الأخبار، لخّص أهم 3 عناوين، ادفعها إلى مستودعي، وأرسل لي إشعاراً».
